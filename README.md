# flight-logger

Бортовой регистратор полёта на ESP32 для самодельных планеров и моделей ракет
плюс симулятор полёта на Python. Регистратор пишет высоту, ускорение и вращение,
а симулятор позволяет сравнить расчёт с реальным полётом.

![Пример: расчёт и синтетический лог](images/example_plot.png)

> На картинке расчёт сравнивается с **синтетическим** логом
> (`data/example_flight_synthetic.csv`), созданным из модели с шумом.
> Реальных полётов пока нет.

## Быстрый старт (симулятор, Windows)
1. Установи Python 3.9+ и библиотеки: `py -m pip install -r requirements.txt`
2. Дважды щёлкни `check_setup.bat`: он покажет, что установлено, а чего не хватает.
3. `run_gui.bat` — окно с ползунками параметров ракеты.
   `run_simulation.bat` — консольный режим: график сохраняется в `simulation/flight_sim.png`.

Или из командной строки:
```
cd simulation
py flight_sim_gui.py
py flight_sim.py --log ../data/example_flight_synthetic.csv
```

## Допущения модели
Одномерный вертикальный полёт, постоянная плотность воздуха, мгновенное
раскрытие парашюта в апогее, нет ветра и наклона траектории. Параметры по
умолчанию (масса, тяга, размеры) — иллюстрация, а не настоящая ракета.

## Формат лога
`t_ms,alt_m,press_pa,ax,ay,az,gx,gy,gz` — тот же, что выводит прошивка v0.1.
